# Public release notes

This repository contains the current Crankshaft launch package and developer build specifications. Listing Tuner is a Crankshaft service. The historical Vehicle Listing Tuner archive is excluded.

The 40 listing reviews retain their source URLs, grades, suggestions and fact-limited copy. Third-party marketplace photo files are omitted from this public repository; the gallery displays clear placeholders. Use dealer-authorized originals for any production photo workflow or public before/after examples.

Open `START-HERE.html` from a downloaded or cloned copy to navigate the package. This repository is a planning and demonstration package, not a live integration or published Crankshaft website.
