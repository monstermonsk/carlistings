## Current status

This is a **design and commercial proposal**, not a deployed integration. There are no live SignalWire, OpenAI, Jev, DMS, CRM, or publishing credentials in this repository. The original monthly prices are restored. The proposed minute allowances require pilot cost data before quoting as fixed commitments. The owner reports about 30,000 total measured tokens per verifier decision; the audio/text split and representative number of decisions per call still need to be measured.

This public repository omits third-party marketplace photo files; the 40 listing grades, draft text, suggestions and source links remain available for review.
